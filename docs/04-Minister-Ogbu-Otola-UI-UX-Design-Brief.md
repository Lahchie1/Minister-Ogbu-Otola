# 4. UI and UX Design Brief

**Product:** Minister Ogbu Otola Personal Website  
**Derived strictly from the accepted PRD**

---

**Audience and tone:**  
Christians (youth to older adults) in Nigeria and serious seekers.  
Tone adjectives: Clear, reverent, trustworthy.

**Reference products:**  
Clean ministry or author sites that prioritise readability and content over visual spectacle. Avoid flashy church sites with heavy animations or generic “inspirational” imagery.

**Color palette:**  
- Primary: Deep navy / charcoal  
- Accent: Muted gold or warm amber (used sparingly)  
- Background: Off-white or very light warm grey  
- Text: Near-black for body, slightly softer for secondary  
- Semantic: Clear green for success, restrained red for errors  
High contrast required.

**Typography:**  
- Clean, highly readable sans-serif for body.  
- Stronger presence for headings.  
- Base size 17–18px, comfortable line height (1.6–1.7).

**Components:**  
- Simple buttons (primary solid, secondary outline).  
- Clean cards for books and resource links.  
- Straightforward forms with clear labels.  
- Minimal navigation.  
- Subtle alerts for form success/error.

**Layout rules:**  
- Single-column or simple two-column max on desktop.  
- Generous spacing.  
- Mobile-first. Content must be readable and tappable on small screens.

**Screen notes:**  
- Home: Clear value proposition + direct paths to Books and Resources.  
- Books: Cover + title + short description + external link(s). Scannable.  
- Resources: Organised by category, clean list with short descriptions.  
- About: Photo (if available), bio, vision — substantive, not promotional.  
- Contact: Minimal fields, clear purpose.

**Accessibility:**  
- WCAG AA contrast minimum.  
- Proper heading hierarchy.  
- Form labels and error messages associated correctly.  
- Touch targets ≥ 44px.  
- Keyboard navigable.

**Interaction states:**  
Standard hover, focus, active, disabled, loading, and error states. No unnecessary motion.

**Assets needed:**  
- Minister photo (appropriate, professional).  
- Book cover images.  
- Simple logo or wordmark if desired (can start with text only).  
- Favicon.
